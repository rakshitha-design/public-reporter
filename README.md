# public-reporter

 🚧 Broken Public Infrastructure Reporter
 
Problem:
People encounter problems such as:
Potholes
Broken streetlights
Damaged footpaths
Overflowing garbage bins
Broken traffic signals
Water leaks
Damaged public toilets
Fallen signs
Blocked drains
Damaged roads

Often, citizens don't know where to report the problem or whether anyone is actually handling it.

App concept
A centralized application where citizens can report infrastructure problems, track their status, and see whether they have been resolved.

Example
A user sees a large pothole.
They open the app and:
Take a photograph.
GPS identifies the location.
Select Pothole.
Add a short description.
Submit.

The system creates:
Issue #10482 — Pothole
Location: XYZ Road
Reported: 10:42 AM
Status: Submitted
Status system

🗺️ Public issue map
Users can see existing reports around them.
For example:
🔴 Unresolved
🟡 Under investigation
🔵 Work in progress
🟢 Resolved
